## Overview

[the-promise-jet.vercel.app](https://the-promise-jet.vercel.app/) Restaurant is the online storefront for THE PROMISE, a Nigerian restaurant based in Abakaliki. It lets hungry customers browse the menu, build a cart, and check out, while giving the kitchen team an admin dashboard to manage dishes and users. Everything syncs in real time so the menu, cart, and user data stay up to date across devices.

## Key Features

*   **Menu browsing and filtering**: Customers can explore Nigerian dishes by category, including soups, swallows, rice, grills, pepper soup, fish, and drinks. A fallback local menu keeps the store populated even when the backend is empty.
*   **Cart and checkout**: Logged-in users add items, adjust quantities, remove entries, and complete a checkout flow with mobile money or card payment options. The cart total updates automatically.
*   **User authentication**: Supports email and password registration, email login, and Google sign-in through Firebase Auth. Sessions persist across page reloads.
*   **Admin dashboard***: Authorized admins can add new food items with image uploads, view the full menu, browse registered users, and switch between dashboard sections from a dedicated side navigation.
*   **Customizable Themes**: Change the application's color scheme to your favorite VS Code theme (GitHub Dark, Dracula, Ayu Dark, Ayu Mirage, Nord, Night Owl).
*   **Responsive Design**: Looks great and functions well across various screen sizes.
